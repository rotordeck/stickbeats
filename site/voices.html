How a voice pack works

One folder per languageThe zip holds SOUNDS/nl (or en, de…). Copy SOUNDS to the root of the SD card; existing files are replaced.
Tell the radioRadio setup → Voice language. Pick the language of the folder. Two voices of the same language share a folder, so install one at a time.
Optional: add a fun themeA voice speaks the numbers and callouts; a sound theme replaces the 70 alert files. Open a hosted voice to download the two combined in one zip.
